# Periodic mean-field remapping

## Defect and correction

During material evolution a uniform reference field transforms as

\[
B(x)=\frac{F\bar B}{\det F},\qquad F=\frac{\partial x}{\partial X}.
\]

The original periodic remap transports the periodic potential, then restores
the initial uniform field in physical coordinates. It discards the fluctuation
generated by deforming the material background. This can erase magnetic growth
even when the existing potential remapper works correctly.

With `-pmf`, the solver records the geometry at the beginning of each material
interval. Before rezoning it converts the transported background's difference
from a uniform physical field into a periodic potential. With `u=X-x`, in 2-D:

\[
\Delta A_z=\bar B_xu_y-\bar B_yu_x.
\]

In 3-D, the corresponding magnetic two-form homotopy is

\[
\Delta a=\left(I+\tfrac12\nabla_xu\right)^T(\bar B\times u).
\]

Its curl is the transported background minus the uniform physical background.
`mean_field.cpp` projects this correction into the potential space, then the
solver applies its existing DG or H(curl) remapper. After reconstruction it
updates the reference geometry. The correction uses geometry and the uniform
field, never an analytic time-dependent magnetic solution.

The native pre-remap field is checked against `curl(A + delta A) + Bbar` before
any remapping or geometry change. Insufficient potential order or a nonuniform
background is rejected. Uniform backgrounds already represented with zero
discrete divergence bypass the singular constant mode of a fully periodic
mixed divergence-projection solve.

## Periodic geometry and moving reference

`SetPeriodic` uses positive lengths to enable images separately in x, y and z.
The density point search centers its periodic images on the unwrapped source
mesh, then searches neighboring images. It handles large rigid translations;
it is not an unlimited search for severely deformed meshes. Unmapped points
cause a clear failure rather than allowing sentinel values into the density.

The original periodic smoother smooths x and restores y/z reference positions,
assuming stationary x walls. A periodic x coordinate has a jump at its seam,
so projecting that coordinate directly into a periodic continuous H1 space is
inappropriate. Fully periodic ALE therefore uses `-mst 1` to restore the
initial reference geometry.

`-crz` translates that reference by the mean displacement of unique true
coordinate DOFs, only in enabled periodic directions. It removes deformation
while retaining bulk translation. Counting true DOFs avoids weighting shared
nodes by MPI partition multiplicity. This is a frame choice, not a claim that
the unweighted nodal mean equals the physical center of mass. Under a uniform
boost the reference shift changes by exactly the boost displacement.

The initial-reference smoother also checks displacement in every enabled
periodic axis when deciding whether to rezone. With `-crz`, bulk translation
is removed from that displacement criterion. Existing x-wall/y-z-periodic
configurations can retain `-mst 3`.

## Fourier initial conditions

Problem 15 initializes uniform density 1, pressure `p`, permeability 1 and
adiabatic index `gamma` in a fully periodic unit domain. It reads a whitespace
separated file:

```text
version pressure gamma
Ux Uy Uz
Bx By Bz
number_of_velocity_modes
nx ny nz ax ay az bx by bz
... one line per velocity mode ...
```

Each mode contributes `a*cos(2*pi*n.x) + b*sin(2*pi*n.x)`. Version 2 adds a
magnetic mode count and magnetic mode lines in the same format. Those magnetic
modes must have nonzero wavevector and transverse coefficients; their periodic
potential is constructed analytically. The uniform magnetic field is carried
separately as the harmonic component. Version 1 contains no magnetic modes.
The reader accepts the original comparison-suite continuum files.

In 2-D, all z wavevectors and z field/velocity coefficients must vanish. The
velocity is projected into the solver's continuous finite-element space;
these are continuum coefficients, not finite-volume cell averages. Coarse
projections need not retain exact continuum solenoidality.

For example:

```sh
mkdir -p output/box3d
mpirun -np 1 ./MHD -p 15 -dim 3 -bic tests/inputs/vortex3d.ic \
  -m mesh/Cube-4x4x4-hex.mesh -rs 0 -ok 2 -ot 1 -or 1 -oa 4 \
  -s 3 -tf 0.2 -cfl 0.4 -cgt 1e-12 -mst 1 -crz -pmf -ma \
  -fsr -fsri 5 -rmv 1 -rme 1 -rma 2 -rmr 3 -bpt 1 \
  -no-pv -no-vis -od output/box3d
```

This coarse example is a regression control, not a converged turbulence run.

## Validation and scope

The geometry regression uses general quadratic deformations in 2-D/3-D and a
background with several nonzero components. The physical shear regression
uses `v_y=sin(pi*x)^2` and `Bx=0.001`. Before magnetic backreaction,

\[
E_B(t)/E_B(0)=1+\pi^2t^2/2.
\]

The primary numerical reference is the same discrete initial condition evolved
without remapping. Corrected and original remaps are compared against it;
the continuum prediction provides a separate interpretation. The long check
retains order-unity growth, avoiding conclusions based on nearly unchanged
magnetic energy.

The correction requires a spatially uniform harmonic background and unchanged
connectivity during each material interval. It uses the supplied remappers;
it does not introduce an r3djl overlap remapper. Its representation requires
potential degree at least the mesh degree in 2-D, and twice the mesh degree in
3-D. It preserves the complete field representation through the background
conversion but does not enforce exact magnetic or total-energy conservation
during general remapping. Magnetic energy, flux and divergence are measured
independently. A helicity invariant for periodic fields with nonzero net flux
is not established by these tests.

## Dependency build example

Install an MPI C/C++ toolchain, HYPRE and METIS 5 development packages first.
For a typical Debian/Ubuntu installation, the following builds the pinned
dependencies under the current directory. Adapt HYPRE/METIS locations on
other systems. `MFEM_USE_DOUBLE` is the MFEM default and was used in validation.

```sh
git clone https://github.com/Nek5000/gslib.git
git -C gslib checkout 375eda25b04205d1f749ab0e00a0bb3f22225b22
make -C gslib -j4 CC=mpicc

git clone https://github.com/ruijie-xi/mfem-develop.git
git -C mfem-develop checkout 842fac6a3b038eaee848921f096e80ceb5f895fa
make -C mfem-develop config MFEM_USE_MPI=YES MFEM_USE_METIS=YES \
  MFEM_USE_METIS_5=YES MFEM_USE_GSLIB=YES \
  GSLIB_DIR="$PWD/gslib/build" HYPRE_OPT=-I/usr/include/hypre \
  HYPRE_LIB=-lHYPRE METIS_OPT=-I/usr/include METIS_LIB=-lmetis \
  PREFIX="$PWD/mfem-install"
make -C mfem-develop -j4
make -C mfem-develop install
make -C MHD-ALE -j4 MFEM_INSTALL_DIR="$PWD/mfem-install"
```
